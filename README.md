# Puddle App

A swamp application created by [Puddle](https://github.com/mesgme/puddle).

## For the requester

```bash
# One-time setup
./puddle-run.sh setup

# Run the app
./puddle-run.sh run --key value

# Check recent runs
./puddle-run.sh status
```
